# TestForge 施工路线（ROADMAP）

> 配套文档：功能需求见 `PRD.md`，范围与验收总口径见 `DEV-SPEC.md`，栈决策见 `adr/0001`。
> 每阶段完成的定义：交付物全部落地 + 门禁全绿（`uv run pytest -q` / `pnpm test` 退出码 0 + 本阶段新增测试）+ 用户可见主链路冒烟通过。

## P0 平台基座（进行中）

**已交付（dec8ec1）**：monorepo 脚手架、统一响应信封、算术验证码（TTL+一次性消费+`captcha_enabled` 开关）、JWT 登录、用户/角色/菜单 RBAC 核心（含菜单环路防护、种子数据）、前端登录页/动态菜单布局/用户管理页、后端 24 + 前端 7 测试、确定性端到端冒烟脚本 `scripts/smoke_login.py`。

**P0 剩余清单**：

| 项 | 要点 |
|---|---|
| 部门管理 | 树形结构、用户归属部门、`available/setting` 语义 |
| 岗位管理 | CRUD + 用户关联岗位 |
| 字典管理 | 类型/数据两级 CRUD，业务处按 dict key 取值 |
| 参数管理 | 键值配置 CRUD + 按 key 读取接口（验证码开关等迁到这里） |
| 操作日志 | 登录日志 + 操作日志，查询/详情/删除 |
| 公告管理 | CRUD + 前端公告展示位 |
| 监控四件套 | 在线用户（踢下线）、服务器监控（CPU/内存/磁盘/进程）、缓存监控（Redis 键浏览/删除）、文件管理（上传目录浏览） |
| 前端补页 | 角色/菜单/部门/岗位/字典/参数/日志/公告/监控 各管理页（可做通用 CRUD 骨架复用） |

**门禁**：九件套契约测试全绿；普通用户越权访问返回 code 403；服务器监控页在开发环境出数。

## P1 测试管理（ALM 核心）

**交付物**：项目（成员/归属部门）、需求、迭代、任务、版本、缺陷（状态流转）、测试用例（模块树+步骤表）、测试计划（关联用例/执行结果汇总）、控制台统计（用例/执行/缺陷/通过率趋势）。

**门禁**：用例树增删改移的领域测试；测试计划关联-执行-统计闭环契约测试；控制台冒烟出数。

## P2 接口测试

**交付物**：接口定义（请求编辑器+环境变量插值）、接口用例（断言规则）、集合、批量回归作业、回归计划、执行引擎（HTTP 客户端+变量渲染+断言）、执行日志与报告、环境管理、**CI Invoke API**（GET Token 鉴权：ping/runrequest/runcollection/runtestcase/runbatch/runplan/runstatus/batchstatus/plan_progress/cancelbatch/coordinator_status 共 12 种 opt；流水线片段生成 cURL/Jenkinsfile/GitLab CI；发布门禁=仅允许引用 active 状态资源）。

**门禁**：执行引擎单测（mock 上游服务：状态码/头/体/JSONPath 断言/变量渲染）；Invoke API 12 opt 契约测试；异步作业轮询语义（runbatch→execution_id→batchstatus）测试。

## P3 AI 层

**交付物**：模型中心（多供应商：OpenAI 兼容协议 + 预设 DeepSeek/Ollama/DashScope + 自定义端点；连通性测试）、聊天助手（多会话/SSE 流式/消息持久化）、Token 计量（按会话/用户/智能体/模型/日维度入账+趋势+排行）、智能体广场（智能体 CRUD/系统提示词/工具绑定/收藏/上架）、Skill 技能（markdown 技能文件管理）、会话记忆、我的空间（个人会话/消耗汇总）、**AI 用例生成工作台**（需求文本→生成用例草稿→人工确认入库，生成记录可追溯）、知识库（可选：文档集/切片/检索接入，无外置检索服务时功能整体可降级关闭）。

**门禁**：供应商适配器单测（OpenAI 兼容协议解析/流式分帧）；Token 计量契约测试（一次对话的 prompt/completion 入账正确）；用例生成闭环冒烟（mock LLM 返回→草稿入库）。

## P4 Web UI 自动化

**交付物**：Playwright 执行器（单机内置模式）、UI 用例（步骤编排：操作/断言/等待）、元素库（定位器集中管理+复用）、录制中心（浏览器操作→步骤回放生成）、执行中心（实时日志/运行状态）、测试报告（步骤级通过率/截图/trace）、浏览器实例页（单机模式：实例列表/启动/销毁；预留分布式扩展点）、**AI Agent 驱动浏览器**（自然语言指令→工具调用→Playwright 动作→截图反馈循环）。

**门禁**：1 条录制→回放用例全链路绿（Playwright 冒烟）；元素库引用替换后用例仍可执行；AI 驱动模式 mock LLM 下完成一个「打开页面→断言标题」任务。

## P5 APP 自动化（最难段）

**交付物**：设备农场（ADB 扫描注册/手工注册/设备目录：品牌/系统/分辨率筛选/状态/收藏/群控/推流节点接入）、设备投屏（scrcpy→WebSocket→前端 canvas，先交付截图+日志模式，实时流为增量）、APP 用例（Appium 步骤编排）、执行中心、性能监控（CPU/内存/帧率采样）、网络抓包（mitmproxy 挂载+请求列表/详情）、Monkey 测试（次数/时长/种子/崩溃捕获）、启动耗时（冷/热启动 am start -W 采样）、报告中心。

**门禁**：1 台模拟器设备全链路冒烟（注册→投屏出图（截图模式可）→跑 1 条用例→出报告）；Monkey 任务可启停且产出崩溃日志（无崩溃时产出统计）。

## P6 任务与工作流

**交付物**：定时任务（APScheduler：任务 CRUD/立即执行/暂停恢复/执行日志/调度器状态面板 start|pause|resume|shutdown|sync）、工作流（定义编排/节点类型注册/发布/实例执行+运行历史）。

**门禁**：定时任务到点触发集成测试（短周期任务）；工作流「定义→发布→执行→历史」闭环契约测试。

## P7 CI 完善与通知

**交付物**：Web UI/App 模块的 CI 触发（复用 Invoke Token 机制）、通知中心（站内通知+WebSocket 实时推/已读/分类）。

**门禁**：UI 用例经 Invoke 触发执行并回传状态；通知从产生到前端实时可见的冒烟。

## P8 分布式化

**交付物**：执行节点 Agent（`apps/agent`：配对码注册→节点身份→长连接心跳→任务分发→日志/画面回传→离线清理）、浏览器实例页切换分布式模式（节点列表/远程浏览器 CDP/Grid/Playwright WS）、设备推流节点接入协议。

**门禁**：两节点场景冒烟（本机起 2 个 Agent 实例）：任务按负载分发、节点离线后任务回收重派、画面回传可见。
