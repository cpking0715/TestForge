# TestForge 产品需求文档（PRD）

> v0.1 · 2026-10-19。本文件是产品功能的**唯一完整需求来源**，以自研产品口吻描述；实现顺序与验收门禁见 `ROADMAP.md`。
> 阅读约定：「应」=必须实现；「宜」=做了更好；「不做」=明确排除。未提及的细节由实现阶段按最简可用原则决定并记 ADR。

## 1. 产品概述

TestForge 是面向内部测试团队的一站式测试平台，覆盖**测试管理 → 自动化执行 → AI 辅助 → CI 集成**全链路。使用者：测试工程师（主体）、开发（提缺陷/看报告）、测试主管（看统计）。

**产品形态**：B/S 单组织部署（内部使用），前后端分离；执行类功能默认单机内置，预留分布式扩展。

**核心用户旅程**：登录 → 建项目 → 写/生成用例 → 组计划执行（手工或自动化）→ 缺陷闭环 → 统计看板 → CI 里一键回归。

## 2. 角色与权限

- 超级管理员（内置，不可删）：全部权限
- 自定义角色：按菜单+操作权限点（`模块:资源:操作` 三段式）授权
- 权限生效于：菜单可见性（前端）+ 接口鉴权（后端，无权限返回 code 403）
- 组织结构：部门树 + 岗位，用户归属部门、可挂岗位；数据按项目成员隔离（非按部门隔离，部门仅用于组织展示）

## 3. 模块需求

### 3.1 认证与会话（已实现 v0.1）

- 账号密码登录 + 算术图形验证码：验证码应 180 秒有效、一次性消费、区分「已过期/答案错误」错误码；提供 `captcha_enabled` 开关（内部部署可关）
- JWT Bearer 鉴权：无效/过期 token 统一 401 信封；前端收到 401 清 token 跳登录
- 不做：扫码登录、第三方 OAuth（扩展点保留）

### 3.2 系统管理（RBAC 九件套）

| 功能 | 需求要点 |
|---|---|
| 用户 | CRUD、重置密码、启停用、绑定角色；超管不可删；用户名唯一 |
| 角色 | CRUD、备注、启停用、**菜单权限分配**（勾选菜单树含按钮权限点）；内置角色不可删 |
| 菜单 | 树形 CRUD；类型：目录/页面/按钮；字段：名称/路由/权限标识/图标/排序/可见；**环路防护**（父不能指向自身或后代；有子菜单不可删） |
| 部门 | 树形 CRUD、用户归属、停用 |
| 岗位 | CRUD、用户可挂多岗位 |
| 字典 | 类型+数据两级 CRUD；业务模块按 key 取枚举（用例等级、缺陷严重度等全部走字典） |
| 参数 | 键值配置 CRUD + `by key` 读取；系统行为参数（如验证码开关）应迁移至此 |
| 日志 | 登录日志（时间/IP/账号/成败）、操作日志（谁在何时对何资源做了何操作）；查询/详情/批量删除 |
| 公告 | CRUD + 发布/撤回；前端顶栏公告入口与已读记录 |

### 3.3 监控管理

- **在线用户**：当前有效会话列表（用户/IP/登录时间），支持强制下线
- **服务器监控**：CPU（核心数/使用率）、内存（总量/已用/进程占用）、磁盘（分区明细）、系统信息（主机/OS/架构/运行时长）、**应用进程运行时**（语言版本/启动时间/安装路径），手动刷新
- **缓存监控**：缓存实例信息、按名字空间浏览键、查看值、删除单键/按前缀清空
- **文件管理**：上传目录浏览（目录树+文件列表）、预览/下载/删除

### 3.4 任务管理

- **定时任务**：cron 表达式任务 CRUD、立即执行一次、暂停/恢复、执行日志（每次运行产出/耗时/结果）、调度器面板（状态/任务列表/启动/暂停/恢复/关闭/手动同步）
- **工作流**：定义（DAG 编排）CRUD、节点类型注册表（类型/参数 schema）、发布（仅已发布定义可实例化）、实例执行与运行历史、节点级执行状态

### 3.5 通知中心

- 站内通知：系统事件（用例被评审、缺陷被指派、执行完成、公告发布）产生通知
- 实时推送（WebSocket）、已读/未读、按类型筛选、全部已读

### 3.6 测试管理（ALM 核心）

| 功能 | 需求要点 |
|---|---|
| 项目 | 名称/编码/负责人/成员/状态；项目是测试数据的顶层隔离边界；归档不可写 |
| 需求 | 标题/描述/来源/关联迭代/状态；可从需求文本触发 AI 生成用例 |
| 迭代 | 名称/时间窗/关联需求/燃尽概览 |
| 任务 | 标题/指派/状态（待办/进行/完成）、关联需求 |
| 版本 | 版本号/说明/关联迭代/发布状态 |
| 缺陷 | 标题/严重程度/优先级/复现步骤/指派/状态流转（新建→确认→修复→验证→关闭/驳回）、附件截图、关联用例与执行记录 |
| 测试用例 | **模块树**（项目内多级目录，用例挂树上，支持拖拽移动）；用例：前置/步骤表（步骤/预期）/级别（字典）/标签/评审状态（草稿/待评审/通过/驳回）；支持导入导出（Excel） |
| 测试计划 | 名称/时间窗/关联用例集合/负责人；执行结果逐用例记录（通过/失败/阻塞/跳过）+ 失败自动关联缺陷；计划级通过率汇总 |
| 控制台统计 | 用例总数/评审数、执行次数/通过率及趋势、缺陷分布（状态/严重度）、项目测试概况表、今日待办（待评审/未执行/待处理缺陷/到期计划）、最近活动流水 |

### 3.7 接口测试

- **接口中心**：接口定义（名称/方法/URL/头/Query/Body/认证），请求体编辑器支持 JSON 高亮；**环境管理**（多环境变量集，`{{var}}` 插值）；单个接口即时调试发送
- **接口用例**：基于接口定义 + 变量覆盖 + **断言规则**（状态码/响应头/响应体 JSONPath 比较）；前后置脚本（提取变量供后续步骤引用）
- **集合**：接口/用例编排成有序集合，步骤间变量传递；批量执行
- **批量回归作业**：选择集合/用例组合成作业，异步执行、进度可查询、可取消
- **回归计划**：定时触发批量作业（挂接定时任务模块）
- **执行日志与报告**：每次执行留痕（请求/响应/断言结果/耗时），按作业聚合报告（通过率/失败明细）
- **AI 编排**：自然语言描述场景 → AI 生成接口调用编排草稿（挂接 AI 层）
- **CI Invoke API**：GET `?project_id&token&opt&target_id[&environment_id]`，12 种 opt（ping/runrequest/runcollection/runtestcase/runbatch/runplan/runstatus/batchstatus/plan_progress/cancelbatch/coordinator_status 及别名）；Token 按项目隔离、可轮换；**发布门禁**：作业仅可引用 active 状态的接口/用例/集合；页面提供 cURL/Jenkinsfile/GitLab CI 片段生成与在线试调

### 3.8 Web UI 自动化

- **UI 用例**：步骤编排（操作：点击/输入/导航/等待/截图/脚本；断言：元素存在/文本/属性），引用元素库定位器
- **元素库**：定位器集中管理（css/xpath/text），被引用处改名自动同步
- **录制中心**：连浏览器录制操作 → 自动生成步骤草稿（可编辑后入库）
- **浏览器实例**：单机模式实例列表（启动/销毁/状态）；扩展点：执行节点（配对码注册、远程 CDP/Grid/Playwright WS 连接）——P8 实现
- **执行中心**：用例/集合执行、实时日志流、并发控制
- **测试报告**：步骤级结果、失败截图、playwright trace 回放、历史趋势
- **AI Agent 驱动**：自然语言任务 → AI 以工具调用方式驱动浏览器（导航/点击/输入/截图回传）→ 迭代至任务完成；执行过程可视化回放

### 3.9 APP 自动化

- **设备农场**：ADB 扫描本机设备注册/手工注册/云真机目录接入；设备属性（品牌/系统/分辨率/状态：空闲|使用中|离线）；筛选（品牌/系统/分辨率/状态/收藏）；**群控**（多设备同步指令）；**推流节点**接入协议（P8 前以截图模式交付）
- **设备投屏**：实时画面（scrcpy 流→WS→canvas）；截屏快照模式为降级基线
- **APP 用例**：Appium 步骤编排（启动/点击/输入/滑动/断言），元素定位复用元素库
- **执行中心**：设备占用/释放、任务排队、实时日志
- **性能监控**：CPU/内存/帧率时序采样与图表
- **网络抓包**：mitmproxy 挂载，请求列表/详情/过滤，HAR 导出
- **Monkey**：次数/时长/种子/事件比例配置，崩溃/ANR 捕获与统计
- **启动耗时**：冷/热启动多次采样（am start -W）统计
- **报告中心**：按执行聚合，含截图/性能曲线/崩溃摘录

### 3.10 AI 层

| 功能 | 需求要点 |
|---|---|
| 模型中心 | 多供应商管理：OpenAI 兼容协议为统一接入层；预设 DeepSeek/Ollama/DashScope（兼容端点）+ 自定义 base_url/key/model；连通性测试；启用/停用 |
| 聊天助手 | 多会话管理、SSE 流式输出、停止生成、消息持久化、上下文长度控制；无可用模型时明确降级提示 |
| Token 计量 | 每次 LLM 调用入账（会话/用户/智能体/模型/日期维度：prompt/completion token）；控制台趋势图、模型消耗占比、智能体/用户/部门排行 |
| 智能体广场 | 智能体 CRUD（名称/头像/简介/系统提示词/绑定的工具与模型/上架状态）；分类/搜索/收藏；对话入口；**配对码**机制：智能体可被外部系统以配对码+密钥调用 |
| Skill 技能 | markdown 技能文件管理（目录/内容/启停），智能体可挂载技能 |
| 会话记忆 | 用户级记忆条目（手动+AI 自动提取），参与对话上下文 |
| 我的空间 | 个人会话列表、消耗统计、收藏 |
| 用例生成工作台 | 输入需求文本/选择关联需求 → AI 按模板生成用例草稿（编号规则 TC-GEN-*）→ 逐条编辑确认入库；生成历史与消耗记录 |
| 知识库 | 可选外置检索服务（文档集/上传/切片/检索 API）；不可用时整体功能隐藏，不阻塞其他 AI 功能 |

### 3.11 持续集成（CI）

- 统一 CI 入口页：按模块（接口/Web UI/App）展示接入状态与 Invoke Token 管理（生成/轮换/复制）
- 流水线片段生成（cURL/Jenkinsfile/GitLab CI YAML）与**在线试调**（真实 Token 发 GET 验证）
- 门禁说明展示（from_invoke 标记 + 发布门禁规则）

## 4. 非功能需求

- **响应信封**：全部 API 统一 `{code, msg, data}`；业务失败 HTTP 200 + code≠0；鉴权 401；无权限 403；未捕获 500
- **安全**：凭据不落源码/日志；密码argon2 哈希；`SECRET_KEY` 必须环境变量注入（生产）；默认种子账号首次登录宜强制改密（P1 实现）
- **性能口径**（内部规模）：100 并发用户、单页 P95 < 1s（不含执行类长任务）；执行类任务全部异步化 + 进度查询
- **部署形态**：docker-compose（PG/Redis）+ nginx 反代 `/api`；单机可跑（SQLite 降级）用于演示与开发
- **可观测**：结构化日志 + x-process-time 头 + 操作/执行两类审计日志

## 5. 明确不做

多租户/SaaS、插件市场（保留扩展点）、扫码/第三方登录、逐像素对标任何现有产品 UI、开放注册。
